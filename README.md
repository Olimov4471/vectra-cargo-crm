# Vectra Cargo CRM

CRM для отдела продаж авиакарго: доска (Yangi sotuv → Qayta sotuv → Doimiy mijoz), список, отчёты и
страница **PNL** (формулы из `Aviakompaniya_PNL_modeli.xlsx` + факт из CRM). Интерфейс на узбекском (латиница).

**Стек:** Node.js 18+ (Express), PostgreSQL, вход по логину и паролю (cookie-сессия на год),
обновления в реальном времени через Server-Sent Events. Права проверяются на сервере.

## Структура
| Файл | Что внутри |
|---|---|
| `server.js` | API, авторизация, роли, правила доступа, realtime |
| `db.js` | Подключение к Postgres (`DATABASE_URL`), без него — временная база в памяти |
| `public/index.html` | Весь интерфейс (доска, список, карточка, отчёты, PNL, сотрудники) |
| `test/smoke.js` | Автотест API (`npm test`) |

## Роли
- **Admin** — видит всё, меняет «Mas’ul xodim» и «Mijoz kodi», удаляет клиентов, утверждает сотрудников, видит PNL.
- **Seller** — видит своих клиентов и неназначенных; новые клиенты автоматически назначаются на него.
- Новый пользователь регистрируется → экран «Tasdiq kutilmoqda» → админ на странице «Xodimlar» привязывает его к имени
  (Muhammad Ali, Bobur, Sirojiddin.P, Sirojiddin.O), отклоняет или отзывает доступ.
- Первый админ создаётся из переменных `ADMIN_LOGIN` / `ADMIN_PASSWORD`. Если они не заданы,
  админом становится **первый зарегистрированный** пользователь.

## Локальный запуск
```bash
npm install
npm start
```
Откройте http://localhost:3000. Без `DATABASE_URL` используется база в памяти: после перезапуска данные стираются.
Автотест: `npm test`.

## Деплой на Railway через GitHub
1. Залейте этот код в репозиторий `vectra-cargo-crm` на GitHub.
2. Railway → **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. В проекте: **+ Create → Database → PostgreSQL**.
4. В сервисе CRM → **Variables** добавьте:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (ссылка на базу)
   - `ADMIN_LOGIN` = ваш логин администратора
   - `ADMIN_PASSWORD` = надёжный пароль (сменить: поменять значение и временно поставить `ADMIN_RESET_PASSWORD=1`)
   - `ADMIN_NAME` = имя (необязательно)
5. Сервис → **Settings → Networking → Generate Domain** — получите адрес вида `https://…up.railway.app`.
6. Каждый `git push` в `main` деплоится автоматически. Проверка работы сервера: `/healthz`.

## Ручной тест-план (10 шагов)
1. **Сохранение входа:** войдите админом, закройте вкладку, откройте снова — вход сохранился. «Chiqish» → снова просит логин.
2. **Подтверждение:** в другом браузере зарегистрируйте `bobur` → экран «Tasdiq kutilmoqda». Админ: Xodimlar → выбрать «Bobur» → Tasdiqlash. Экран продавца откроется сам (≤5 с).
3. **Видимость:** админ создаёт клиента с Mas’ul = Muhammad Ali — Бобур его не видит. Клиент без Mas’ul виден Бобуру. Клиент, созданный Бобуром, получает Mas’ul = Bobur.
4. **Полный цикл:** клиент на «Yangi sotuv» → перетащить в «Sotildi» → $500, 50 kg → клиент на «Qayta sotuv», этап «Yangi mijoz». Ещё 3 продажи → после третьей он на «Doimiy mijoz» (история: «3 marta qayta sotuv bo’ldi…»).
5. **Окно продажи:** пустая сумма или 0 → ошибка «Sotilgan summani ($) yozing»; «Bekor qilish» → ничего не меняется.
6. **Причина «Sotib olmadi»:** меньше 3 символов → ошибка; отмена → этап не меняется; с причиной → карточка исчезает с доски, причина видна в «Hisobotlar».
7. **Sifatli lead:** снять галочку → обязательная причина; у клиента с продажами галочку снять нельзя.
8. **Массовые действия:** в «Ro’yxat» отметьте 3 клиентов → «Sotib olmadi» → одна причина для всех; «Sotildi» → окно продажи для каждого.
9. **Уникальный код:** админ ставит клиенту код другого клиента → «Bunday kod band yoki bo’sh», значение откатывается.
10. **Формулы отчёта** (пример: 10 лидов, 6 качественных, 3 покупателя, у одного 2 продажи; продажи $100, $200, $300, $400):
    Umumiy lead = 10 · Sifatli = 60% · Konversiya = 3/6 = 50% (от лидов 30%) · Yangi sotuv = 3 · Qayta sotuv = 4−3 = 1 ·
    O’rtacha chek = 1000/4 = $250 · LTV = 1000/3 = $333.33.
    **PNL:** при значениях из Excel (7.5 / 10 / 0.5, расходы 620 + 1980, план 1500 кг) 1-й месяц: выручка $15,000, чистая прибыль $400,
    безубыточность 1,300 кг, нужный план 2,300 кг — совпадает с листом «PNL».

## Realtime и одновременная правка
Изменения приходят всем открытым вкладкам сразу. Если двое правят одного клиента одновременно, второй получит сообщение
«Bu mijozni boshqa xodim o’zgartirdi…», и карточка обновится — данные не перезатираются молча.
История (Tarix) только дополняется, автор записи определяется сервером.
